Here’s a **summary of what this lab does**:  

---

### 🔐 **Lab 4 Summary: Implementing Cryptography with Python**

---

### 🎯 **What You’ll Learn:**

- **Symmetric encryption** using AES.
- **Asymmetric encryption** using RSA.
- **Hashing** using SHA-256.
- **Digital signatures** using RSA for authenticity and integrity.

---

### 🛠️ **What You’ll Do:**

1. **AES Encryption/Decryption**
   - Write Python code to encrypt and decrypt messages with AES.

2. **RSA Encryption/Decryption**
   - Generate RSA keys and use them to encrypt/decrypt messages.

3. **SHA-256 Hashing**
   - Generate and compare SHA-256 hashes for different inputs.

4. **Digital Signatures**
   - Create and verify digital signatures using RSA key pairs.

---

This lab teaches you how to **build basic cryptographic functions in Python**—like **encryption, hashing, and digital signatures**—to understand how these tools work behind the scenes and how they're applied in the real world.
