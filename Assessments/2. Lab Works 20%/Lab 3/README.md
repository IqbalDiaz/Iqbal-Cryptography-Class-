Here’s a **summary of what this lab does**:  

---

### 🔐 **Lab 3 Summary: Exploring Cryptographic Tools – Hashing, Encryption & Digital Signatures**

---

### 🎯 **Objectives:**
- Learn how to **encrypt and decrypt files** using symmetric (AES) and asymmetric (RSA) encryption.
- Understand **hashing with SHA-256** for verifying file integrity.
- Create and verify **digital signatures** using RSA and SHA-256.

---

### 🛠️ **What You’ll Do:**

1. **AES Encryption/Decryption**  
   - Encrypt and decrypt a file using AES-256 in CBC mode.

2. **RSA Encryption/Decryption**  
   - Generate RSA key pairs, encrypt a message with the public key, and decrypt it with the private key.

3. **SHA-256 Hashing**  
   - Generate and compare hashes before and after modifying a file to understand integrity checks.

4. **Digital Signatures**  
   - Sign a file using RSA with SHA-256 and verify the signature. Test what happens if the file is tampered with.

---

This lab teaches you how to **use cryptographic tools like OpenSSL** for real-world security tasks — including **encryption, hashing, and digital signatures**.
